# TANK / 90 · 坦克大战

向红白机坦克大战致敬的原创浏览器游戏。无依赖，无需安装，直接双击 `index.html` 即可游玩。

也可以用 Node.js 启动：

```sh
npm start
```

浏览器打开 http://127.0.0.1:3000 。

## 操作

| 动作 | 玩家 1 | 玩家 2 |
| --- | --- | --- |
| 移动 | W / A / S / D | 方向键 |
| 射击 | 空格 | Enter |
| 暂停或继续 | P / Esc | P / Esc |

在开始界面选择单人或双人。手机提供玩家 1 的触屏按键。声音默认关闭，可在右上角打开。

每关消灭 20 辆敌方坦克即可进入下一关，每关奖励 1000 分。砖墙可被子弹破坏，钢墙需要三级火力。水面无法通过，草丛可以遮挡坦克。基地遭到任意一方的子弹攻击，或所有玩家耗尽生命，作战结束。

闪光敌军掉落补给：★ 升级火力、✹ 消灭当前敌军、◷ 冻结敌军 8 秒、▤ 基地钢墙保护 15 秒、+ 增加一条生命。坦克重生获得短暂无敌保护。最高纪录保存在当前浏览器中。

像素画面与音效均由程序生成，未使用原版游戏素材。中文字体有在线字体增强，离线时自动回退到系统字体。
