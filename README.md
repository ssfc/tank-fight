# TANK / 90 · 坦克大战

向红白机坦克大战致敬的原创浏览器游戏。无依赖，无需安装，直接双击 `index.html` 即可游玩。

也可以用 Node.js 启动：

```sh
npm start
```

浏览器打开 http://127.0.0.1:3000 。

## 操作

| 动作 | 玩家 1 | 玩家 2 |
| --- | --- | --- |
| 移动 | W / A / S / D | 方向键 |
| 射击 | 空格 | Enter |
| 暂停或继续 | P / Esc | P / Esc |

在开始界面选择单人或双人。手机提供玩家 1 的触屏按键。声音默认关闭，可在右上角打开。

单人模式自动配备一辆绿色 AI 队友（车顶标有 AI），拥有独立的 3 条生命，自动寻路和射击，优先拦截靠近基地的敌军，不会攻击基地和基地围墙，也不会拾取道具。AI 击杀计入本局得分。玩家生命耗尽仍会结束单人作战。双人模式的绿色坦克由玩家 2 操作。

每关消灭 20 辆敌方坦克即可进入下一关，每关奖励 1000 分。砖墙可被子弹破坏，钢墙需要三级火力。水面无法通过，草丛可以遮挡坦克。基地遭到任意一方的子弹攻击，或所有玩家耗尽生命，作战结束。

地图采用红白机《Battle City (J)》原版 35 关，按原版顺序循环。半块砖墙、半块钢墙、水面、树林、冰面和基地周围的留白由原始关卡数据解码；玩家在底部两侧格子中央出生。第一关可以从左侧出生点向上走，经基地上方的横向通道前往右侧，不需要击毁砖墙。

闪光敌军掉落补给：★ 升级火力、✹ 消灭当前敌军、◷ 冻结敌军 8 秒、▤ 基地钢墙保护 15 秒、+ 增加一条生命。坦克重生获得短暂无敌保护。最高纪录保存在当前浏览器中。

像素图形与音效均由程序生成。地图布局来自原版游戏，敌人行为、AI 队友和部分玩法为本项目实现，并非完整模拟原版程序。中文字体有在线字体增强，离线时自动回退到系统字体。

## 地图数据来源

`stages.js` 保存 35 条 91 字节的地图记录，来源为 [NES-Games-Disassembly / Battle City](https://github.com/cyneprepou4uk/NES-Games-Disassembly/tree/df2c8e55e7f13e5792482527db9e7c9e4a84c6e1/Battle%20City)，固定到提交 `df2c8e55e7f13e5792482527db9e7c9e4a84c6e1`。按 `bank_FF.asm` 的 `tbl_F07A_stage_data` 顺序读取，按 `tbl_DACB_block_data` 解码半块地形，再应用基地留白和出生格清空。

可用 `python scripts/import-stages.py` 从上述固定版本重新生成地图数据。游戏运行不需要网络；测试会核对源记录 SHA-256，并检查第一关的实际通行路线及全部 35 关的出生空间。地图布局的原始权利属于 Namco / Bandai Namco。
